# Release notes

## 2.0.0 — 30 October 2026

The default workflow now assesses a fixed X–Y relationship in matched contextual settings. It proposes four pairs per round, reviews their design and selects two using prospective relationship-change potential and coverage. Two independent assessments reverse setting and fact order. Search continues to the configured round budget.

The release adds:

- Private planning memory containing earlier proposals, selected comparisons and numeric assessments.
- A simple one-pass baseline and common blinded comparison, with two eligibility judgments and one shared coverage coder.
- Yield, conservative magnitude, observable-attribute coverage and conceptual coverage, with their denominators retained.
- Five corrected paper-based input examples, English prompt and payload exports, and a deterministic offline demo.
- OpenAI GPT-6 Astra configuration, non-streaming Python SDK transport, bounded concurrency and recorded requests for resume.
- The current Figure 1 in SVG, PDF and PNG, and the finalized five-study summary.

The prior categorical-choice runtime is no longer the default. Existing website URLs are retained. The archived five-study findings are separate from new runs and from the offline software fixture. Existing categorical-choice checkpoints cannot be resumed with this release; retain their original runtime or start a new study.

No API credentials, provider debugging runs or research PDFs are included.
